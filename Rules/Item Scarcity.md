When players go shopping, not every item is guaranteed to be available. Scarcity reflects how often a given rarity tier can actually be found in a market, shop, or from a merchant — roll percentile dice (d100) to determine availability.

Thalyra:

| Rarity    | Availability |
| --------- | ------------ |
| Common    | 100%         |
| Uncommon  | 66%          |
| Rare      | 33%          |
| Very Rare | 10%          |
| Legendary | 5%           |
| Artifact  | Unique       |
