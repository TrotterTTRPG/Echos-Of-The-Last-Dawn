# Working in this campaign vault

This repository is an Obsidian vault for a D&D campaign, not a software application. Start campaign work with `Campaign Reference/Campaign Home.md`, then `Current Campaign State.md` and the relevant source notes. The reference folder summarizes the review through session 008; confirm later session records before relying on it as current.

## Preserve continuity

- Distinguish recorded play, established setting lore, DM secrets, preparation, and proposals. An outline or conditional branch in Completed Events does not prove an outcome happened.
- Prefer recorded outcomes over older static descriptions. Keep the detailed source notes and link to them when updating summaries.
- Do not invent answers to unresolved mysteries or contradictions. Record the question and its sources. Mella's uncertain origin is explicitly intentional, including for the DMs.
- The user confirmed this vault is private to the DMs. Hidden lore belongs here, but keep player/character knowledge separate from DM knowledge when generating scenes and recaps.
- Follow the campaign's stated 2014 rules and explicit house rules. Menus of options are not selections. Old character PDFs and saved fight states are not current resource ledgers.
- Use existing characters, places, and institutions before creating replacements. Check exact names and spelling; similar names need not be the same person.

## Obsidian documents

Use ordinary Markdown and vault-relative wikilinks. Use explicit paths for repeated filenames such as Notes, Outline, and index. Verify new links resolve. Keep read-aloud text separate from DM secrets, mechanics, and possible outcomes.

For NPC creation, consult the existing `.claude/skills/create-npc/SKILL.md`. For other content, use `Campaign Reference/Rules and Content Guide.md` and the relevant PC, lore, and scenario sources.

After recording new play, update the current-state and active-thread references with evidence. Do not treat Obsidian workspace tabs, calendar UI selection, or plugin data as authoritative campaign chronology. Preserve unrelated live Obsidian changes during Git operations.
